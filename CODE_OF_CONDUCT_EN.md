# Code of Conduct

[Русский](CODE_OF_CONDUCT.md) | **English**

This Code of Conduct defines the rules for communication and collaboration in “Let's Go! Slavgorod”. The project focuses on an application and public materials about urban and suburban transport in Slavgorod, so respectful communication, careful handling of data, and a clear distinction between this independent project and official organizations are especially important.

## Scope

This code applies to:

- issues, pull requests, reviews, and other discussions in this repository;
- suggestions and messages related to the project website and documentation;
- discussions of routes, stops, schedules, and data sources within the project;
- other public channels where a participant acts on behalf of the project or clearly represents themselves as a project participant.

## Expected behavior

Project participants should:

- communicate respectfully and critique ideas, code, and data rather than people;
- make feedback specific and provide reproducible examples when possible;
- cite a verifiable source when correcting schedule or transport data, when such a source is available;
- remember that schedule errors can affect real users and avoid presenting knowingly unverified information as fact;
- respect privacy and never publish another person's personal data, private application logs, tokens, signing keys, or other secrets;
- accept corrections constructively and acknowledge mistakes;
- help keep discussions understandable for users and developers with different levels of experience.

## Unacceptable behavior

The following is not acceptable:

- insults, humiliation, harassment, threats, or targeted provocation;
- discriminatory or degrading statements about people or groups;
- publishing another person's personal information without explicit consent;
- publishing private logs, secrets, keys, tokens, or other sensitive information;
- spam, unsolicited advertising, or mass messages unrelated to the project;
- deliberately spreading false information about routes, stops, departure times, or schedule sources;
- using vulnerability reports for coercion, blackmail, or public disclosure of sensitive details before a fix is available;
- impersonating the Slavgorod city administration, government institutions, transport operators, municipal organizations, or presenting this application as their official service;
- pursuing or harassing a participant outside the project because of a disagreement that occurred in a project discussion.

## Schedule and data disputes

When participants disagree about a route, stop, time, or data source, verifiable facts and current public sources should take priority. Discussion should focus on which information is most appropriate to show users and how the application should behave when information is conflicting or outdated.

Personal attacks against data authors, transport operators, users, or developers do not help resolve the issue and are not acceptable.

## Reporting a violation

If a violation can be discussed publicly without exposing private information, it may be raised in the relevant issue or discussion.

If the situation involves personal data, threats, harassment, vulnerability details, or other sensitive information, contact **vladislav-olyushin@mail.ru** directly.

When reporting, include a link or relevant context, a short description of the problem, and only the material necessary to review it.

## Moderation and enforcement

Depending on the situation, the project maintainer may:

1. ask a participant to change their wording or stop inappropriate behavior;
2. hide or remove a comment that violates this code;
3. close a discussion, issue, or pull request when constructive dialogue is no longer possible;
4. temporarily restrict participation;
5. block a participant for serious or repeated violations.

Decisions are made with consideration for context, severity, repetition, and impact on other participants.

## Independent project status

“Let's Go! Slavgorod” is an independent, unofficial project. Participation in development or discussion does not grant anyone the right to represent the Slavgorod city administration, government institutions, LLC “Slavgorodskoye ATP”, MUP “Torgovy Ryad g. Slavgorod”, or any other official organization.

The purpose of this code is to keep the project useful, safe, and comfortable for collaboration.
