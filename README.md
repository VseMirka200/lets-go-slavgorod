Текущая версия — **3.0.2**, минимальная версия Android — **7.0 (API 24)**.

Приложение позволяет искать маршруты и остановки, смотреть ближайшие отправления, добавлять маршруты в избранное, выбирать источник расписания и получать уведомления об изменениях.

> [!IMPORTANT]
> Проект независимый и не является официальным источником транспортной информации.
