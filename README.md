## Описание
**Поехали! Славгород** — это удобное приложение для жителей и гостей города Славгород, которое помогает быстро найти нужный автобус и узнать точное время его отправления.

### Основные возможности:
- Полное расписание всех городских и пригородных маршрутов
- Поиск маршрутов по номеру или названию
- Избранные рейсы для быстрого доступа к нужному времени
- Уведомления о приближающемся отправлении
- Автоматические обновления расписания через GitHub
- Высокая производительность и стабильность благодаря комплексному тестированию

---

## Возможности приложения

### Расписание
- Просмотр полного расписания для каждого маршрута
- Разделение по дням недели (будни/выходные)
- Подсветка ближайших рейсов

### Избранное
- Добавление рейсов в избранное одним касанием
- Быстрый доступ к часто используемым рейсам
- Настройка уведомлений для избранных рейсов
- Управление списком избранного

### Уведомления
- Push-уведомления о приближающемся отправлении

### Обновления
- Автоматические обновления расписания через GitHub
- Уведомления о доступности новых версий

## Технические особенности
- **Jetpack Compose** - современный UI toolkit
- **Room Database** - локальное хранение данных
- **Kotlin Coroutines** - асинхронное программирование
- **Clean MVVM архитектура** - чистая и масштабируемая архитектура с Use Cases
- **Удалённая загрузка данных** - расписание загружается из GitHub в реальном времени
- **Многоуровневое кэширование** - GitHub → Локальный кэш → Assets → Hardcoded
- **Автоматические обновления** - система проверки и установки обновлений приложения
- **CI/CD** - автоматизация сборки и тестирования через GitHub Actions
- **Статический анализ** - контроль качества кода с Detekt
- **Comprehensive Testing** - полное покрытие тестами с Mockito и Robolectric
- **Performance Testing** - тестирование производительности критических операций

## Установка

### Требования
- Android 7.0 (API 24) или выше
- 50 МБ свободного места
- Интернет-соединение для обновлений расписания

### Установка из APK
1. Скачайте последний APK из раздела [Releases](https://github.com/VseMirka200/lets-go-slavgorod/releases)
2. Включите "Установка из неизвестных источников" в настройках Android
3. Установите APK файл
4. Запустите приложение

## Тестирование

### Покрытие тестами
Проект включает комплексное тестирование всех ключевых компонентов:

#### Unit тесты
- **BusRouteRepository** - тестирование репозитория данных с Mockito
- **RoutesViewModel** - тестирование ViewModel с Robolectric
- **Constants** - валидация констант приложения
- **Utils** - тестирование утилитарных функций

#### Performance тесты
- **Загрузка данных** - тестирование производительности загрузки маршрутов
- **Поиск и фильтрация** - тестирование скорости поиска по большим наборам данных
- **Управление памятью** - контроль использования памяти
- **Параллельные операции** - тестирование thread safety

#### Integration тесты
- **Пользовательские сценарии** - end-to-end тестирование основных функций
- **Навигация** - тестирование переходов между экранами
- **Избранное** - тестирование функциональности избранных маршрутов

### Технологии тестирования
- **Mockito** - мокирование зависимостей
- **Robolectric** - тестирование Android компонентов
- **Kotlin Coroutines Test** - тестирование асинхронного кода
- **JUnit 4** - основной фреймворк тестирования
