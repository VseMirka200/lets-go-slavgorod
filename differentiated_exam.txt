Разработайте систему управления складом с использованием ООП, расширив 
функциональность из задания 1.

ТРЕБОВАНИЯ:
1. Создайте классы: Product, Category, Warehouse, Supplier.
2. Класс Product должен содержать: название, цена, количество, категория, 
   поставщик, дата поступления, минимальный остаток.
3. Класс Category должен содержать: название, описание, список товаров.
4. Класс Warehouse должен управлять товарами, реализовать методы: добавление товара, 
   продажа товара (уменьшение количества), пополнение склада, поиск товара, 
   проверка минимального остатка, получение товаров с низким остатком.
5. Класс Supplier должен содержать: название, контакты, список поставляемых товаров.
6. Используйте инкапсуляцию (приватные поля с __).
7. Добавьте валидацию данных и методы: расчет общей стоимости склада, 
   расчет стоимости по категориям, проверка наличия товара.
8. Реализуйте наследование: создайте класс PerishableProduct (наследник Product) 
   с дополнительными полями (срок годности, дата производства).

КРИТЕРИИ ОЦЕНКИ:
- Корректная реализация классов (25 баллов)
- Использование принципов ООП (наследование, инкапсуляция) (30 баллов)
- Функциональность системы (25 баллов)
- Валидация данных и бизнес-логика (10 баллов)
- Демонстрационная программа (10 баллов)

ЗАДАНИЕ 3: РАБОТА С БАЗОЙ ДАННЫХ (1.5 часа)
-------------------------------------------------------------------------------
Создайте приложение для учета склада с использованием SQLite, интегрировав 
функциональность из заданий 1 и 2.

ТРЕБОВАНИЯ:
1. Создайте таблицы: categories (id, name, description), suppliers (id, name, contact), 
   products (id, name, price, quantity, category_id, supplier_id, min_stock, arrival_date), 
   transactions (id, product_id, transaction_type, quantity, transaction_date, notes).
2. Реализуйте CRUD операции для всех таблиц.
3. Используйте параметризованные запросы и FOREIGN KEY для связей.
4. Создайте класс DatabaseManager для работы с БД.
5. Реализуйте методы: добавление товара, продажа товара (с записью транзакции), 
   пополнение склада (с записью транзакции), поиск товаров с низким остатком, 
   просмотр истории транзакций, расчет общей стоимости склада.
6. Добавьте обработку исключений и транзакции для операций продажи/пополнения.
7. Используйте JOIN и агрегатные функции (SUM) для расчетов.

КРИТЕРИИ ОЦЕНКИ:
- Создание структуры БД с связями (20 баллов)
- Реализация CRUD операций (30 баллов)
- Использование параметризованных запросов, JOIN и агрегатных функций (20 баллов)
- Транзакции и обработка ошибок (15 баллов)
- Демонстрация работы (15 баллов)

ЗАДАНИЕ 4: ТЕСТИРОВАНИЕ (1 час)
-------------------------------------------------------------------------------
Напишите unit-тесты для системы управления складом из заданий 1-3.

ТРЕБОВАНИЯ:
1. Используйте pytest для написания тестов.
2. Создайте тесты для классов Product, Category, Warehouse, Supplier (минимум 15 тестов).
3. Создайте тесты для DatabaseManager и операций с БД (минимум 10 тестов).
4. Тестируйте обработку ошибок с pytest.raises().
5. Используйте parametrize для тестирования с разными данными.
6. Используйте fixtures для создания тестовой БД.
7. Достигните покрытия кода минимум 80%.

КРИТЕРИИ ОЦЕНКИ:
- Количество и качество тестов (40 баллов)
- Тестирование граничных случаев и ошибок (25 баллов)
- Использование pytest возможностей (fixtures, parametrize) (20 баллов)
- Покрытие кода (15 баллов)
