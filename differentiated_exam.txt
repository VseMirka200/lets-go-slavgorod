ЗАДАНИЕ 1: СТРУКТУРНОЕ ПРОГРАММИРОВАНИЕ (1.5 часа)
================================================================================

Создайте базовую версию приложения для управления выбранной предметной областью 
с использованием принципов структурного программирования.

ТРЕБОВАНИЯ:
1. Реализуйте функции для базовых операций с данными:
   - Добавление новой записи
   - Удаление записи
   - Поиск записи (по одному или нескольким критериям)
   - Просмотр всех записей
   - Редактирование записи
2. Добавьте обработку ошибок (некорректный ввод, пустые данные, дубликаты, 
   несуществующие записи).
3. Создайте меню выбора операции с возможностью возврата в главное меню.
4. Используйте только структурные конструкции (if-else, циклы, функции).
5. Разделите код на функции: ввод данных, валидация данных, обработка данных, 
   вывод результата.
6. Реализуйте дополнительную функциональность:
   - Сортировка записей (по одному или нескольким полям)
   - Фильтрация записей (по критериям)
   - Подсчет статистики (количество, суммы, средние значения)
7. Данные храните в памяти (списки, словари).

ВАЖНО: Это базовая версия приложения, которая будет развиваться в следующих заданиях.

================================================================================
ЗАДАНИЕ 2: ОБЪЕКТНО-ОРИЕНТИРОВАННОЕ ПРОГРАММИРОВАНИЕ (2 часа)
================================================================================

Переработайте приложение из задания 1, используя принципы ООП. Сохраните всю 
функциональность, но перепишите код с использованием классов и объектов.

ТРЕБОВАНИЯ:
1. Создайте классы для основных сущностей предметной области (минимум 3-4 класса).
2. Каждый класс должен содержать:
   - Атрибуты (характеристики сущности)
   - Методы для работы с данными
   - Валидацию данных при создании и изменении
3. Создайте управляющий класс (менеджер/сервис) для координации работы всех сущностей.
   Этот класс должен содержать методы из задания 1, но реализованные через объекты.
4. Используйте инкапсуляцию:
   - Приватные поля (с __)
   - Геттеры и сеттеры (property)
   - Публичные методы для доступа к данным
5. Реализуйте наследование:
   - Создайте базовый класс для общих свойств
   - Создайте класс-наследник с дополнительными полями и методами
6. Добавьте валидацию данных:
   - Проверка корректности введенных данных
   - Проверка бизнес-правил (ограничения, лимиты)
   - Обработка исключительных ситуаций
7. Сохраните всю функциональность из задания 1:
   - Все операции (добавление, удаление, поиск, редактирование)
   - Сортировка и фильтрация
   - Подсчет статистики
   - Меню и интерфейс
8. Данные по-прежнему храните в памяти (списки объектов).

ВАЖНО: Приложение должно работать так же, как в задании 1, но код должен быть 
организован с использованием ООП.

================================================================================
ЗАДАНИЕ 3: РАБОТА С БАЗОЙ ДАННЫХ (1.5 часа)
================================================================================

Добавьте к приложению из задания 2 работу с базой данных SQLite. Приложение должно 
сохранять данные в БД и загружать их при запуске.

ТРЕБОВАНИЯ:
1. Создайте структуру базы данных:
   - Таблицы для всех основных сущностей (минимум 3-4 таблицы)
   - Связи между таблицами через FOREIGN KEY
   - Промежуточные таблицы для связи многие-ко-многим (если необходимо)
2. Создайте класс DatabaseManager для работы с БД:
   - Методы для создания таблиц
   - Методы для каждой CRUD операции
   - Методы для выполнения бизнес-операций
   - Методы для получения связанных данных
3. Интегрируйте DatabaseManager в управляющий класс из задания 2:
   - При создании/обновлении/удалении объектов - сохранять в БД
   - При запуске приложения - загружать данные из БД
   - Все операции должны синхронизироваться с БД
4. Используйте параметризованные запросы для всех операций с данными.
5. Реализуйте сложные запросы:
   - JOIN для получения связанных данных из нескольких таблиц
   - Агрегатные функции (COUNT, SUM, AVG, MAX, MIN) для расчетов
   - Группировка данных (GROUP BY)
6. Добавьте обработку транзакций:
   - Использование транзакций для операций, изменяющих несколько таблиц
   - Откат транзакций при ошибках
   - Обработка исключений и ошибок БД
7. Сохраните всю функциональность из заданий 1 и 2:
   - Все операции работают через БД
   - Сортировка, фильтрация, статистика используют SQL запросы
   - Меню и интерфейс остаются прежними

ВАЖНО: Приложение должно работать так же, как в задании 2, но данные теперь 
сохраняются в БД и загружаются при запуске.

================================================================================
ЗАДАНИЕ 4: ТЕСТИРОВАНИЕ (1 час)
================================================================================

Напишите unit-тесты для финального приложения из заданий 1-3.

ТРЕБОВАНИЯ:
1. Используйте pytest для написания тестов.
2. Создайте тесты для всех классов из задания 2:
   - Тесты конструкторов и инициализации
   - Тесты методов работы с данными
   - Тесты валидации данных
   - Тесты бизнес-логики
   - Минимум 15 тестов для классов
3. Создайте тесты для DatabaseManager из задания 3:
   - Тесты CRUD операций
   - Тесты сложных запросов (JOIN, агрегатные функции)
   - Тесты транзакций
   - Тесты обработки ошибок
   - Минимум 10 тестов для БД
4. Создайте интеграционные тесты для управляющего класса:
   - Тесты полных сценариев работы приложения
   - Тесты взаимодействия классов с БД
   - Минимум 5 интеграционных тестов
5. Тестируйте обработку ошибок:
   - Используйте pytest.raises() для проверки исключений
   - Тестируйте граничные случаи
   - Тестируйте некорректные входные данные
6. Используйте возможности pytest:
   - @pytest.fixture для создания тестовых данных и тестовой БД
   - @pytest.mark.parametrize для параметризованных тестов
   - @pytest.mark для группировки тестов
7. Организуйте тесты:
   - Отдельные файлы для тестов классов, БД и интеграционных тестов
   - Использование conftest.py для общих fixtures
   - Понятные имена тестов, описывающие проверяемую функциональность
8. Достигните покрытия кода минимум 80% (используйте pytest-cov).
