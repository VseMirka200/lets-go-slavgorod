# 📚 Документация проекта

Папка `docs/` разделена так, чтобы публичный сайт и материалы для пользователей не смешивались. ✨

- `assets/` — изображения, стили и JavaScript для GitHub Pages;
- `index.html`, `schedule.html`, `releases.html` — публичные страницы сайта;
- `guides/` — инструкции для участников и пользователей;
- `policies/` — политика конфиденциальности, безопасности и кодекс поведения;
- `release/` — история изменений.
