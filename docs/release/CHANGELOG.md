# История изменений

Версия сборки, указанная в проекте, — 3.1.2. Сведения о фактически опубликованных версиях и APK доступны в [GitHub Releases](https://github.com/VseMirka200/lets-go-slavgorod/releases).

## Не выпущено

- Расписание ведётся в Google Таблице и передаётся приложению и сайту через Apps Script.
- Добавлены настраиваемый источник приложения и резервная копия расписания на GitHub с автоматизацией её обновления.
- Добавлены раздел обратной связи с выбором темы письма и информация о времени загрузки расписания.
- Обновлены документация, сведения на сайте и [руководство по передаче расписания](../guides/SCHEDULE_DATA.md).

Эти записи описывают состояние проекта и не подтверждают публикацию новой сборки, сайта или workflow. При выпуске перенесите соответствующие изменения в раздел версии и добавьте дату.
