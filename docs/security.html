Политика безопасности

Здесь собран публичный документ о том, как проект старается защищать сайт, приложение и связанные с ними данные от типичных рисков.

1. Общие принципы

Мы стараемся поддерживать сайт и приложение в безопасном состоянии, чтобы снизить риск несанкционированного доступа, потери данных и случайного раскрытия информации.

  • используем только публичные страницы и понятные ссылки на документы;
  • ограничиваем доступ к служебным данным и настройкам проекта;
  • стараемся вовремя обновлять зависимости, скрипты и контент сайта;
  • не размещаем на сайте лишние персональные данные без необходимости.
2. Какие меры применяются

Для защиты проекта используются базовые организационные и технические меры: проверка ссылок, контроль публикаций, хранение документации в открытом доступе только там, где это действительно нужно, и аккуратная работа с внешними сервисами.

  • публичные страницы доступны по прямому URL без дополнительных переходов;
  • адреса для обратной связи и документация размещаются отдельно от кода приложения;
  • при работе с внешними источниками мы стараемся использовать только те данные, которые нужны для работы сервиса;
  • если обнаруживается ошибка или уязвимость, мы стараемся исправить её как можно быстрее.
3. Ограничения

Ни один сайт или приложение не может быть абсолютно защищённым. Поэтому мы не обещаем полную недоступность всех угроз, но стараемся разумно снижать риски и не оставлять известные проблемы без внимания.

  • пользователь сам должен проверять ссылки и не передавать данные на сторонних подозрительных ресурсах;
  • при использовании внешних сервисов их собственные правила и политика безопасности тоже остаются важными;
  • если требуется передача чувствительных данных, она должна происходить только через доверенные каналы.
