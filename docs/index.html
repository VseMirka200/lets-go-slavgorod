Поехали! Славгород

Неофициальное справочное приложение о маршрутах и расписании Славгорода. Здесь можно быстро найти нужный маршрут, открыть его расписание, закрепить избранное и следить за обновлениями.

GitHub RuStore Google Play
Группа ВКонтакте

Быстрый доступ к маршрутам и расписанию

Быстрый доступ к маршрутам и расписанию

  • открыть список маршрутов в одном экране;
  • найти нужный автобус по номеру или названию;
  • посмотреть расписание по направлениям и остановкам;
  • быстро вернуться к нужному маршруту без лишних шагов;
  • закрепить маршруты и сменить источник данных в любой момент.

Полезные функции для повседневных поездок

Полезные функции для повседневных поездок

  • просмотр расписания городских и пригородных маршрутов;
  • поиск маршрутов по номеру и названию;
  • сохранение нужных рейсов для быстрого доступа;
  • системные уведомления об изменениях расписания;
  • экспорт локальных логов и настройка отображения.
