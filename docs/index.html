Расписание

Откуда берутся данные

Сайт и приложение получают расписание из общего источника. Если он недоступен, сайт показывает ранее сохранённые в браузере данные при их наличии.

В приложении сохраняется локальная копия расписания. Время загрузки не означает, что перевозчик подтвердил расписание: перед поездкой уточняйте важные отправления.
