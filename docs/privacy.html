Политика конфиденциальности

Здесь описано, какие данные обрабатывает приложение «Поехали! Славгород», зачем они нужны и как ими управлять.

1. Кто мы

Проект «Поехали! Славгород» поддерживается независимым разработчиком VseMirka200. Приложение не является официальным приложением администрации города, перевозчиков или других муниципальных организаций.

  • Контакт для связи: vladislav-olyushin@mail.ru
  • Исходный код: GitHub
2. Какие данные обрабатываются

Приложение работает без аккаунта и не требует ввода имени, номера телефона или контактов. Основная часть данных хранится только на устройстве пользователя.

  • настройки отображения, темы и закреплённые маршруты;
  • кэш расписания и локальные журналы приложения;
  • выбранный URL источника расписания, если пользователь изменил его вручную;
  • разрешение на системные уведомления, если пользователь включил уведомления о расписании.
3. Зачем это нужно

Данные используются только для работы приложения: отображения маршрутов, сохранения пользовательских настроек, обновления расписания и отправки системных уведомлений об изменениях расписания, если пользователь включил эту функцию.

  • для загрузки и отображения расписания приложение обращается к выбранному пользователем источнику по сети;
  • при включённых уведомлениях приложение может показывать локальные системные уведомления об изменениях расписания;
  • логи можно экспортировать только по инициативе пользователя через системный экран отправки.
4. Передача и хранение

Приложение не продаёт данные и не передаёт их третьим лицам для рекламы или аналитики. Локальные данные хранятся на устройстве и могут быть сброшены через настройки.

  • расписание может загружаться только с публичных HTTP(S)-адресов, которые пользователь видит в настройках;
  • при ручном экспорте журналов файл передаётся только через выбранное пользователем приложение;
  • после сброса настроек локальный кэш и пользовательские предпочтения удаляются.
5. Права пользователя

Пользователь может отключить уведомления, изменить источник расписания, сбросить локальные данные и не использовать экспорт логов.

Если нужно удалить или уточнить данные, свяжитесь с разработчиком по адресу vladislav-olyushin@mail.ru.
