# Privacy Policy

[Русский](PRIVACY.md) | **English**

“Let's Go! Slavgorod” is an independent unofficial application. It does not require an account and does not request a name, phone number, or contact list for its core functionality.

## Data processed by the application

Most data is stored locally on the user's device:

- theme, display, and interface behavior settings;
- favorite routes;
- schedule cache;
- local application logs;
- the selected schedule source URL if the user changes it manually;
- the state of the system notification permission.

## How the data is used

Local data is used to operate the interface, preserve user settings, display routes and schedules, and provide notifications about schedule changes when the user enables that feature.

To download a schedule, the application connects over the network to the selected data source. Such a network request technically exposes to the operator of that server the standard information required for an HTTP(S) connection, such as the IP address and technical request parameters, to the extent determined by that server.

## Data sharing

The project does not use user data for advertising and does not claim to sell user data. Exporting local logs is performed only at the user's initiative through the system sharing interface.

When an external schedule source is used, the privacy policy and rules of that source's operator also apply.

## Managing data

The user can:

- disable system notifications;
- change the schedule source;
- reset local settings and cache using the application;
- choose not to export logs;
- remove application data through Android by clearing app data or uninstalling the application.
