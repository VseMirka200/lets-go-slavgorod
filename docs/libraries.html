Используемые библиотеки

Здесь собраны основные зависимости проекта и их роль в приложении «Поехали! Славгород».

1. Платформа
  • AndroidX Core KTX
  • Lifecycle Runtime, ViewModel Compose, Lifecycle Process
  • Activity Compose
  • Compose BOM, UI, Material, Material 3, Navigation Compose
2. Данные и фоновые задачи
  • Kotlin Coroutines
  • AndroidX DataStore Preferences
  • Gson для JSON-парсинга
  • OkHttp для сетевых запросов
3. Логирование и DI
  • Timber для логирования
  • Koin Android и Koin Compose для внедрения зависимостей
4. Тестирование
  • JUnit
  • Kotlin Test
  • Mockito и Mockito Kotlin
  • Robolectric
  • MockWebServer
  • AndroidX Test Core, JUnit Ext, Espresso, Compose UI Test
5. Сборка
  • Android Gradle Plugin
  • Kotlin Android и Kotlin Compose Compiler
  • Detekt
  • Desugar JDK Libraries
