# Политика конфиденциальности

«Поехали! Славгород» — независимое неофициальное приложение. Оно не требует создания аккаунта и не запрашивает имя, номер телефона или список контактов для основной работы.

## Какие данные обрабатываются

Основная часть данных хранится локально на устройстве пользователя:

- настройки темы, отображения и поведения интерфейса;
- кэш расписания;
- локальные журналы приложения;
- состояние разрешения на системные уведомления.

Сайт сохраняет ранее загруженное расписание в хранилище браузера, а файлы страниц — в кэше service worker для повторного открытия. Android может включать данные приложения в системное резервное копирование в зависимости от настроек устройства.

## Для чего используются данные

Локальные данные нужны для работы интерфейса, сохранения пользовательских настроек, отображения маршрутов и расписания, а также уведомлений об изменениях расписания, если пользователь включил эту функцию.

Для загрузки расписания приложение и сайт обращаются к Google Apps Script. Сетевой запрос технически раскрывает владельцу соответствующего сервера стандартную информацию, необходимую для HTTP(S)-соединения, например IP-адрес и технические параметры запроса в объёме, определяемом самим сервером.

## Передача данных

Проект не использует пользовательские данные для рекламы и не заявляет о продаже пользовательских данных. Экспорт локальных журналов выполняется только по инициативе пользователя через системный интерфейс отправки.

При использовании внешнего источника расписания применяется политика конфиденциальности и правила владельца этого источника.

При выборе обратной связи приложение открывает ВКонтакте или почтовое приложение с подготовленным письмом. Содержимое письма пользователь может проверить и изменить; отправка выполняется пользователем в выбранном приложении. Эти внешние сервисы обрабатывают данные по собственным правилам.

## Управление данными

Пользователь может:

- отключить системные уведомления;
- сбросить локальные настройки и кэш средствами приложения;
- не использовать экспорт журналов;
- удалить данные приложения средствами Android, очистив данные или удалив приложение.
- удалить данные сайта и его кэш средствами браузера.
