# Политика безопасности

Безопасность приложения, сайта проекта и пользовательских данных рассматривается как часть качества проекта.

## Сообщение об уязвимости

Не публикуйте сведения о потенциальной уязвимости в открытом issue, pull request, discussion или комментариях.

Отправьте описание на [**vsemirka200@bk.ru**](mailto:vsemirka200@bk.ru). По возможности приложите:

- затронутую версию приложения или компонент сайта;
- условия и шаги воспроизведения;
- ожидаемое и фактическое поведение;
- оценку возможного воздействия;
- минимальный пример или подтверждение проблемы без публикации чувствительных данных.

Не отправляйте реальные пароли, ключи подписи, токены, персональные данные пользователей или иные секреты.

## Область действия

К этой политике относятся:

- Android-приложение «Поехали! Славгород»;
- исходный код этого репозитория;
- публичный сайт в каталоге `docs/`;
- обработка источников расписания, сетевых запросов, локальных настроек, кэша и журналов приложения.

Сторонние сервисы и внешние источники данных имеют собственные политики безопасности. Проблему во внешнем сервисе следует также сообщать его владельцу, если это безопасно и уместно.

## Базовые меры проекта

Приложение использует сетевые разрешения только для функций, которым требуется сеть, и отдельное разрешение на системные уведомления. В манифесте отключён обычный cleartext-трафик, а локальные файлы для экспорта передаются через `FileProvider` с ограниченной выдачей URI-разрешений.

Секреты release-подписи не должны храниться в репозитории. Они передаются через переменные окружения или параметры системы сборки.

Адрес расписания и ответ Apps Script публичны: не размещайте в таблице, URL или JSON пароли, токены и личные данные. Ограничьте право редактирования таблицы и развёртывания скрипта доверенными редакторами. На сайте JSONP выполняет код ответа, поэтому источник должен быть доверенным.
